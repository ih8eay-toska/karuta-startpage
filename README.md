# 桃花 · Personal Startpage

**桃花 (Táohuā, “peach blossom”)** is a personal browser homepage built around a collection of illustrated card themes. Choose a card from either rotating wheel to change the page palette, then keep the selected card and its details in view above the search panel.

## What it includes

- **Card themes:** dark and light collections, with each card setting its own colors and accent glow. The selected theme is remembered between visits.
- **Search:** search Google or YouTube with the engine picker, or use `g` and `yt` prefixes in the search field.
- **Quick links:** six theme-colored slots attach to the search panel, three on each side. Add a site through the in-page dialog; its favicon is fetched automatically, and you can remove it with the small × control. Links are stored in this browser.
- **Saved pages:** four language tabs—Saved, Enregistré, 已保存, and 保存済み—each with three editable website slots. Entries are stored in this browser.
- **Persistent wheels:** wheel positions are remembered between visits.
- **Music:** play 冷夜 from the compact utility strip beneath the search bar. Playback and seeking stay visible; the speaker button reveals volume, a percentage readout, and mute/unmute. The popover closes with Escape or a click outside.
- **Clock:** a live clock defaults to GMT+7, with quieter seconds. Press the globe-and-GMT pill to choose the sign and hour in an anchored wheel popover, then press Done. Offsets from GMT-12 to GMT+14 are remembered without seasonal clock changes. Previously saved timezones are converted to their current GMT offset.

## Run locally

Open `index.html` in a browser. The page is plain HTML, CSS, and JavaScript and has no build step.
